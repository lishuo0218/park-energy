### 业务流程拆解

要回答：问题发生在哪一步，为什么要这样划分智能体？

1. 先画人工现状泳道，写出触发、输入、8–15个处理步骤、交接和异常。
2. 区分判断点与执行点；按使用的数据、权限、模型能力与失败方式组合执行步骤。
3. 在不可逆动作前设置确定性校验；为低置信、缺资料、冲突和越权安排具名人工接收人。

交付链：现状流程 → 失败方式 → 智能体/工具边界 → 校验与人工升级路径

### 业务结果与不可逆风险矩阵

- REQ-2 总表-分表-设备归属差异应形成可追溯的异常解释闭环
  依据：energy-consumption-f10、energy-consumption-f12、energy-consumption-f00、energy-consumption-f01、energy-consumption-f14
  推导：月底核对需4人天，流程节点耗时未分别量；空调与生产设备归属不清，关键说明常留在便签或群里而未随单据交接。异常定位三天到半天的起止和成功口径未定，不能直接认定瓶颈节点。
  判断：候选需求；需用结果与不可逆风险矩阵比较，P0/P1/P2不等于已完成价值风险评分。
  下一步：用两栋楼一个月历史数据回放，逐笔记录抄表、归集、负荷对比、定位、建议、人工确认各节点等待与处理时间，并建立差异清单和交接说明。先由林亦舟复核、唐映秋分派；验收需顾明岚明确定位起止、统计周期和账实差异低于1%的计算口径。
- REQ-3 安全负荷、人工签核与不控制边界须作为建议流程的停止条件
  依据：energy-consumption-f40、energy-consumption-f52、energy-consumption-f22、energy-consumption-f44、energy-consumption-f42
  推导：不得以节能为由影响安全负荷或生产保障；范围仅限耗能解释与节能建议，不执行设备控制或自动计费；节能项目专员不能代替电气安全主管签核。规则冲突、资料缺依据或倍率异常时应转人工，触及停止条件应暂停试点。
  判断：候选需求；需用结果与不可逆风险矩阵比较，P0/P1/P2不等于已完成价值风险评分。
  下一步：用规则冲突和倍率异常样本回放，检查是否触发停止、是否记录转人工原因、接手人和确认时间，并验证建议不能替代设备操作。由傅景签核停止条件清单和规则冲突处理方式；触发即暂停并由负责人复盘，作为验收条件。
- REQ-4 只读接口的数据新鲜度和故障降级需可验证
  依据：energy-consumption-f32、energy-consumption-f34、energy-consumption-f35、energy-consumption-f30
  推导：系统仅允许只读能耗与设备表，不能自动断电或调整配电参数；计划每15分钟更新，超过周期标为待刷新；接口中断时使用带时间戳的上一份快照并显示暂未更新，重连后按业务编号去重补齐，避免重复待办。多系统尚无统一业务状态视图。
  判断：候选需求；需用结果与不可逆风险矩阵比较，P0/P1/P2不等于已完成价值风险评分。
  下一步：模拟接口中断和延迟，核对快照时间戳、待刷新标识、重连去重键和现有人工流程是否延续。由秦芮确认刷新周期与去重规则；验收只读边界不被突破、同一待办不重复触发，状态超期必须显式提示。
- REQ-5 跨部门交接以接手人确认和业务版本作为完成口径
  依据：energy-consumption-f23、energy-consumption-f25、energy-consumption-f51、energy-consumption-f54
  推导：交接至少包含业务编号、当前版本、处理状态、未解决事项和接手人，对方确认接手才结束本岗待办；异常分派超时升级，跨岗问题需明确下一责任人。服务侧逐笔采集交接等待和重新联系次数，不能用通知数量代替实际完成量；租户反馈需关联原业务编号和资料版本，争议由叶书受理、唐映秋核对。
  判断：候选需求；需用结果与不可逆风险矩阵比较，P0/P1/P2不等于已完成价值风险评分。
  下一步：抽取10笔跨部门异常或租户反馈，逐笔记录等待时长、重新联系次数、业务编号与资料版本、接手确认和争议处理。由叶书受理、唐映秋核对、顾明岚确认完成口径；验收以实际完成确认而非通知量计，未确认不承诺时限或赔偿。
- REQ-6 审计与反馈迭代需保留版本、事实引用和人工改动
  依据：energy-consumption-f45、energy-consumption-f15、energy-consumption-f55、energy-consumption-f43
  推导：每次建议需保留业务编号、资料版本、事实引用、建议结果、人工改动和签核人，审计应能重建抄表到人工确认的本次处理；错误结果不能覆盖原记录。试点每周收集误判和未解决问题，先复测再更新规则版本。评价记录暂保留90天，真实期限仍待组织确定。
  判断：候选需求；需用结果与不可逆风险矩阵比较，P0/P1/P2不等于已完成价值风险评分。
  下一步：抽取若干建议记录重建抄表到确认链路，检查资料版本、事实引用、人工改动与签核字段是否齐全，并确认不记录口令或不必要个人信息。90天暂留用于回放，真实期限由傅景按组织规则确认；复测未达标不得更新规则版本。
